How to make the access token
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and tap Generate new token.
  2. Name it Brew app and pick an expiry (a year is fine).
  3. Under Repository access, choose Only select repositories and pick brew-data.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as it is.
  5. Generate, copy the token, and paste it above. It stays on this phone and can only touch brew-data.
